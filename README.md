# 💍 Shadi Ka Card

**Shadi Ka Card** is a modern digital wedding invitation website designed to share wedding details beautifully and effortlessly online.

🔗 **Live Website:** https://shadi-ka-card.vercel.app/

---

## ✨ Features

- Elegant and mobile-friendly wedding invitation
- Displays couple names, event details, and schedule
- Image-based design for a premium look
- Location / route links for easy navigation
- Fast and lightweight performance

---

## 🧰 Tech Stack

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Assets:** Static images & optimized media

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or later)
- npm or yarn

### Run Locally

```bash
git clone https://github.com/<your-username>/shadi-ka-card.git
cd shadi-ka-card
npm install
npm run dev
```


Open http://localhost:3000 in your browser.

## 🌐 Deployment

The project is deployed using Vercel, providing fast builds, automatic deployments, and global CDN support.
